My first serious encounter with AI was in late 2022, when I started using GitHub Copilot in VS Code. I wasn't using ChatGPT at the time. Seeing Copilot understand the code I was writing and predict what I wanted to write next genuinely surprised me.

At the time, I wasn't working a full-time job. I was taking on small backend and frontend projects as a freelancer, and Copilot helped me a lot. It made me faster and, looking back, AI was already helping me make money.

Today, I sometimes ask myself:

**"Why didn't I continue learning AI back then?"**

I had actually started, but at some point I stopped. I don't think it was simply because I didn't have enough time.

I started blogging in 2023, mostly writing on Medium about small Go projects and things I learned while exploring Rust. Eventually, I stopped using Medium and decided to publish everything on my own blog instead.

The period when I first became interested in AI was also a difficult time in my life. I had lost someone in my family, and looking back, I understand better why I couldn't continue.

Now I have the time again, and I want to use it to learn AI.

But I don't want to learn AI only through theory.

I learn best by building things. So I want to continue developing with Go while learning AI, starting with small projects, understanding how these systems actually work, and gradually moving toward more complex ones.

## How I See the Future of AI

When I think about the future of AI, chatbots aren't the first thing that comes to mind.

I think chatbots are only the beginning.

The bigger change is AI moving from systems that simply **answer questions** to systems that can **take action toward a goal**.

I see it moving in this direction:

**Human → describes the desired result → AI plans → writes code → uses tools → runs tests → returns the result**

Instead of telling the computer how to perform every individual step, we increasingly describe what we want to achieve.

For example, a developer might simply say:

> "Add this feature without breaking the existing architecture. Write the tests and make sure everything passes."

The AI could inspect the codebase, create a plan, modify files, run commands, read test failures, fix its mistakes, and continue until the task is complete.

That's where things become much more interesting to me.

AI stops being just a tool that generates code and starts becoming a system that can work toward a goal.

## What Happens After 2030?

I think the next step will be AI systems that can work for much longer periods of time.

Instead of:

**Question → AI → Answer**

we may move toward:

**Goal → AI agents → tools → actions → result**

An agent could maintain a software project, monitor tests, investigate bugs, review dependencies, and ask a human only when an important decision needs to be made.

Later, multiple specialized agents could work together: one for backend development, another for frontend, testing, security, or infrastructure.

And then there is the physical world.

As AI and robotics continue to develop together, the same agent loop could eventually leave the computer:

**See → understand → plan → act → observe → improve**

By 2035 or 2040, some of today's advanced AI capabilities may feel completely normal. AI systems could become increasingly connected to robots, machines, vehicles, and other parts of the physical world.

I don't know exactly when this will happen, and nobody really knows what 2040 will look like.

But I remember being amazed in 2022 when Copilot completed a few lines of my code.

That was only a few years ago.

This time, I don't want to just use AI. I want to understand how it works and build things with it.

And I want to start from something I already know:

**Go.**

I've been seriously learning AI for about two weeks now.

One of my goals is simply to keep going and see where this journey takes me.

Maybe I'll stop halfway again.

Or maybe, just like AI, **I'll keep learning, improving, and evolving too.**

Let's see.
